# Contributing

Start with README.md and AGENTS.md. Discuss a bounded feature in a pull request with a concrete before/after behavior and commands actually run. Keep model/live-runtime evidence separate from mocks and prepared examples.

Run npm ci and npm run verify. Include browser evidence for changed UI flows, and rendered-audio evidence for changed synthesis behavior. Do not commit credentials, real user conversations, node_modules, or generated bundles. Credit upstream code/assets and compatible licenses.
